Period block, fixed

Week / Month / Year now spans the full width. Below it is a separate row with ‹ › arrows and the period name in the middle. Tapping the name opens the From/To wheels. The › arrow is greyed out when the next period hasn't happened yet. Every tab uses this same block.

Tags tab

  • Your tags sit in one row you can scroll sideways. Tap to pick them; picked tags turn mint with an ✕.
  • With two or more tags, a small "Any tag / All tags" switch appears.
  • Then come In / Out / Net, the transaction count and the comparison, a wave over time (switch between Spent / Earned / Moved), categories, by account, and recent transactions.
  • "All 48 ›" opens Transactions with these tags already filtered, as it does today.
